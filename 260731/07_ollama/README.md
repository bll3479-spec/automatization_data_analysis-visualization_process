# 과제 7. HTML 대시보드 + Ollama 언어모델 채팅 연동

## 무엇을
과제 6 대시보드에 채팅 UI를 추가하고, 질문 시 **현재 필터 기준의 대시보드 요약 통계를
시스템 프롬프트에 담아** 로컬 Ollama(`localhost:11434`)의 `/api/chat`으로 요청, 응답을 표시.

## 사용 모델
- 기본: **gemma4:e2b** (로컬 설치 모델)
- 선택: gpt-oss:20b-cloud (클라우드 — 답변 품질 비교용, UI 드롭다운에서 전환)

## 실행 방법 (로컬)
1. Ollama를 CORS 허용 상태로 실행:
   - Windows PowerShell: `$env:OLLAMA_ORIGINS="*"; ollama serve`
   - (또는 시스템 환경 변수에 `OLLAMA_ORIGINS=*` 등록 후 Ollama 재시작)
2. 모델 설치 확인: `ollama pull gemma4:e2b`
3. `index.html`을 브라우저로 열기 → 채팅 패널 상단에 "✅ Ollama 연결됨"이 뜨면 준비 완료
4. 예시 질문 버튼 또는 직접 입력으로 질문

## 동작 방식
- 매 질문마다 `buildSummary()`가 **현재 필터가 적용된** 통계를 새로 계산해 시스템 프롬프트 구성:
  - 필터 상태(지역·품질), 주택 수, 평균/중앙값/최고가
  - 지역별 평균가 상위 5, 품질 등급별 평균가
  - 사전 분석 결과(과제 1~5에서 도출): 상관계수, Key Influencers 배수, 회귀모델 R²
- 예: NoRidge 필터 상태에서 질문하면 "41채, 평균 $335,295" 기준으로 답변
- 최근 대화 4턴을 함께 전송해 후속 질문 문맥 유지
- 연결 실패 시 점검 안내(실행 여부 / 모델 설치 / CORS) 표시
- 모델 응답·사용자 입력은 `textContent`로만 DOM에 삽입 (HTML 주입 방지)

## 예시 질문 (내장 버튼)
- "이 지역에서 가격을 올리는 가장 큰 요인은?"
- "OverallQual과 SalePrice 관계를 설명해줘."
- "현재 필터 기준으로 데이터를 요약해줘."

## 산출물

  프롬프트에 반영되는 것 확인용)

  (제출 요건 — 파일명 예: `캡처_QA_요인질문.png`, `캡처_QA_품질관계.png`)
