# 과제 6. HTML 대시보드 개발

## 무엇을
순수 HTML/CSS/JS + Chart.js로 주택가격 정적 웹 대시보드를 구현.
KPI 카드 3종 + 차트 3종 + 필터 2종(지역·품질)이 전부 연동되는 인터랙티브 페이지.

## 어떻게
- **실행**: `index.html`을 브라우저로 열기만 하면 됨 (서버 불필요)
  - 데이터는 `data.js`로 내장(CSV→JSON 변환, 1,460행) — `fetch` 없이 로드되므로
    `file://`로 열어도 CORS 문제가 없음
  - Chart.js v4.4.3도 로컬 동봉(`chart.umd.min.js`) — 오프라인에서도 동작
- **필터 연동**: 지역/품질 드롭다운 조작 시 KPI 3종 + 차트 3종이 동시에 갱신
  (Power BI 슬라이서의 교차 필터링과 동일한 개념을 JS로 구현)
  - 지역 필터 선택 시: 지역 막대차트는 전체 지역을 유지하되 선택 지역만 본색, 나머지는 흐림 처리
  - 품질 필터도 같은 방식으로 품질 분포 차트에서 해당 등급만 강조
- **라이트/다크 모드**: OS 설정(prefers-color-scheme)에 자동 대응

## 구성 요소

| 요구사항 | 구현 |
|---|---|
| KPI 카드 3종 | 평균 판매가 · 최고 판매가 · 주택 수 (필터 반영) |
| 차트 ① | 지역별 평균 판매가 — 가로 막대, 평균가 내림차순 정렬 |
| 차트 ② | 거주 면적(GrLivArea) vs 판매가 산점도 — 점 색을 품질(OverallQual) 1~10에 따라 파랑 단일 색상 램프(연함→진함)로 인코딩, 하단에 램프 범례 |
| 차트 ③ | 품질 등급별 주택 수 분포 — 세로 막대 |
| 필터 1개 이상 | 지역 + 품질 드롭다운 2종 + 초기화 버튼 |
| 상호작용 | 모든 차트에 호버 툴팁(값·면적·품질·지역), 필터-전체 연동 |

## 디자인 노트
- 색은 검증된 데이터비주얼 팔레트 사용: 계열색 파랑(#2a78d6/#3987e5),
  순차(크기) 인코딩은 파랑 단일 색상 램프 — "순차 = 한 색상, 연함→진함" 원칙
- 막대 두께 제한(≤24px)·데이터 끝 4px 라운드·헤어라인 그리드 등 마크 스펙 적용
- 텍스트는 항상 텍스트 토큰(잉크 색), 데이터 색은 마크에만 사용

## 검증
- 기본 상태 평균 $180,921 · 1,460채 → 과제 1(pandas)·과제 4(Power BI) 결과와 일치
- NoRidge 필터 시 평균 $335,295 · 41채 → 과제 1 지역별 평균 순위와 일치
- 산점도에서 과제 1과 동일한 이상치 2건(4,500sqft↑ 저가) 확인 가능
